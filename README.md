# ML Portfolio — Four End-to-End Projects

Four self-contained machine learning projects, from basic regression through
to a deployed, API-served model with a live dashboard. Each project is a
complete, independently runnable mini-repo with its own data, notebook,
generated outputs, and documentation.

| # | Project | Task Type | Highlights |
|---|---|---|---|
| 1 | [Student Performance Prediction](Task1-StudentPerformance) | Regression | 3 models compared · EDA · feature correlation analysis |
| 2 | [Classification Project](Task2-Classification) | Binary classification | Real-world medical dataset · 3 algorithms · ROC/AUC, confusion matrices |
| 3 | [End-to-End Prediction System](Task3-EndToEnd) | Classification | Messy data cleaning · feature engineering · `GridSearchCV` tuning · CLI predictor |
| 4 | [Deploy an ML Model](Task4-Deployment) | Regression + MLOps | FastAPI service · Pydantic validation · live HTML/JS dashboard |

## Repository structure

Every project follows the same layout:

```
Task<N>-<Name>/
├── data/            # raw and/or processed datasets (CSV)
├── images/          # EDA and evaluation plots (PNG), generated by the pipeline
├── outputs/         # trained model files, metrics, predictions
├── notebooks/       # Jupyter notebook walking through the full pipeline
├── pipeline.py       # standalone script that reproduces data/images/outputs
├── requirements.txt
└── README.md        # dataset details, methodology, results, how to run
```

Task 4 additionally has an `app/` folder containing the FastAPI service and
dashboard frontend. Task 3 additionally has `predict_cli.py`, a command-line
prediction interface.

## Projects at a glance

### 1 — Student Performance Prediction (`Task1-StudentPerformance/`)
Predicts a student's final exam score from study hours, attendance, previous
scores, sleep, and background factors. Compares Linear Regression, Decision
Tree, and Random Forest.
**Result:** Linear Regression best, R² = 0.71.

### 2 — Classification Project (`Task2-Classification/`)
Binary classification on the real-world Breast Cancer Wisconsin (Diagnostic)
dataset — malignant vs. benign tumor diagnosis from cell-nuclei measurements.
Compares Logistic Regression, Random Forest, and SVM with a full metric
suite (accuracy, precision, recall, F1, ROC-AUC).
**Result:** all three models score >95% accuracy; Logistic Regression edges
out on F1 and ROC-AUC.

### 3 — End-to-End Prediction System (`Task3-EndToEnd/`)
A loan-approval classifier built on deliberately messy synthetic data
(inconsistent text casing, missing values, income outliers). Full pipeline:
cleaning → EDA → feature engineering → `GridSearchCV` hyperparameter tuning
→ evaluation, plus `predict_cli.py`, an interactive command-line interface
for making predictions against the trained model.

### 4 — Deploy an ML Model (`Task4-Deployment/`)
Trains and hyperparameter-optimizes a regression model, then deploys it as a
**FastAPI** service (`app/main.py`) with Pydantic-based input validation
(range checks, enum checks, HTTP 422 on invalid input) and a `/health`
endpoint. A bundled static dashboard (`app/static/index.html`) calls the API
directly from the browser — verified working end-to-end (health check,
valid predictions, and validation-error handling all tested against a
running instance).

## Tech stack
- **Data & modeling:** Python, pandas, NumPy, scikit-learn
- **Visualization:** Matplotlib, Seaborn
- **Notebooks:** Jupyter
- **Deployment:** FastAPI, Uvicorn, Pydantic
- **Frontend:** vanilla HTML/CSS/JavaScript (no build step)

## Getting started

Each project is independent — `cd` into the one you want and follow its own
`README.md`. General pattern:

```bash
cd Task<N>-<Name>/
pip install -r requirements.txt
python pipeline.py                     # regenerates data/images/outputs
                                        # (Task 4 uses train_and_optimize.py)
jupyter notebook notebooks/*.ipynb     # explore the full walkthrough
```

For Task 4's live API + dashboard:
```bash
cd Task4-Deployment/
pip install -r requirements.txt
python train_and_optimize.py
cd app && uvicorn main:app --reload --port 8000
# open http://127.0.0.1:8000/
```

For Task 3's CLI predictor:
```bash
cd Task3-EndToEnd/
python predict_cli.py
```

## A note on data sources
Tasks 1, 3, and 4 use realistic **synthetic** datasets (generated with
deliberate real-world quirks — missing values, outliers, inconsistent text
formatting, and only partially predictive features — so reported metrics
reflect genuine model performance rather than an artificially easy problem).
Task 2 uses scikit-learn's built-in **Breast Cancer Wisconsin (Diagnostic)**
dataset, a real, widely-used dataset in medical ML research.
